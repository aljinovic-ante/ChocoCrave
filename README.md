# ChocoCrave

**ChocoCrave** is a **full-stack web application** designed to showcase and manage a curated collection of craft chocolates. Built with **React.js** on the frontend and **Express.js** with **MongoDB** on the backend.

## Features

### 🌟 General Features
- Explore a variety of craft chocolates
![Screenshot_1](https://github.com/user-attachments/assets/102724ac-43ec-4c2f-a0f6-7e7565f1a03c)

- View detailed information about each chocolate, including:
  - Price
  - Cocoa percentage
  - Color (dark, milk, white, ruby, etc.)
  - Type (dark chocolate, milk chocolate, ruby chocolate, etc.)
 
![Screenshot_3](https://github.com/user-attachments/assets/339a7aad-8eb9-4ffc-84de-97dca1db78ae)

- Access manufacturer profiles with details such as:
  - Year of establishment
  - Country
  - Company description
  - Logo

### 🔐 User Authentication
- **Register**, **Login**, and **Logout** functionality secured with JWT authentication.
- Role-based access control:
  - **Admin** users can create, edit, and delete chocolates and manufacturers.
  - **Regular** users can browse chocolates and manufacturers only.

![Screenshot_6](https://github.com/user-attachments/assets/8b231338-bf89-4d09-8181-2d1e1e6a33cc)

### 🛠️ Admin Features
- Manage chocolates, manufacturers and users through intuitive CRUD interfaces.
![Screenshot_2](https://github.com/user-attachments/assets/d98aab5a-a355-4a44-bd13-6d841d52547d)


### 🛒 Additional Functionality
- **Favorites**: Save chocolates to your personal favorites list for quick access.
![Screenshot_4](https://github.com/user-attachments/assets/381b1d63-b490-4e0a-9af0-212785f44854)

- **Shopping Cart**:
  - Add or remove chocolates from the cart.
  - Clear the cart upon checkout with a single click.
